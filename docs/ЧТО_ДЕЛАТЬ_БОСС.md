## Тебе на Bothost (3 шага)

1. Обнови код из git (pull / redeploy), как обычно.
2. В настройках окружения Bothost добавь (или проверь):

```
BOT_TOKEN=...твой токен...
OWNERS=@твой_логин
DB_PATH=/data/ispoved.db
API_PORT=8080
API_HOST=0.0.0.0
API_CORS=*
WEBAPP_URL=https://vaggo01.github.io/ispoved/
SHEETS_URL=
```

`DB_PATH` — путь **на постоянный диск** Bothost (как у них в инструкции volume). Если не знаешь — спроси в поддержке Bothost «куда писать файл базы».

3. Перезапусти бота.

## Если карта в Mini App «не грузится»

Значит с телефона **не достучаться до API** бота.

1. Узнай публичный URL Bothost (типа `https://что-то.bothost...`).
2. Напиши мне этот URL — я впишу в `config.js` на сайте.  
   Или сам: файл `ispoved/config.js` на Pages:

```js
window.ISPOVED_API = "https://ТВОЙ-URL-С-BOTHOST";
```
