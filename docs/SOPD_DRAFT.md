# Черновик текста для гостя (СОПД / согласие)

> Это **черновик для продукта**, не юридическая консультация.  
> Заказчик может вставить в Mini App / на стену / в оферту. При необходимости — юрист.

---

## Короткий (для галочки в Mini App)

«Нажимая «Выпустить карту», я соглашаюсь на обработку моих персональных данных (имя, телефон, дата рождения, идентификатор Telegram) лаундж-баром «Исповедь» (г. Пермь) в целях программы лояльности: начисление и списание бонусов, уведомления об акциях и визитах, обратная связь. Данные хранятся, пока я пользуюсь программой, и могут быть удалены по запросу администратору.»

---

## Чуть полнее (если попросят «документ»)

**Оператор:** лаундж-бар «Исповедь», г. Пермь, ул. Николая Островского, 93Д.

**Цели:** программа лояльности (бонусы, уровни, штампы, купоны), связь с гостем в Telegram, статистика посещений.

**Данные:** имя, фамилия (если указана), телефон, дата рождения, Telegram ID / username, история начислений и визитов.

**Срок:** до отзыва согласия или удаления карты по запросу.

**Права гостя:** запросить копию данных, исправление, удаление — через сообщение директору в боте или администратора заведения.

**Передача третьим лицам:** не продаём. Технические подрядчики (хостинг, Telegram) обрабатывают данные только для работы сервиса.
